# 自动化基础底座设计

自动化中心是跨产品域基础底座，不属于 Collect、Data Lake 或 ETL Pipeline。它统一承载模板目录、工作流、调度定义和运行实例。

对象链路：`产品域产出 → 模板 → 工作流 → 调度/事件 → 运行 → 任务实例`。

每个对象必须具有唯一 `product_domain`：`ai-collect`、`data-lake`、`etl-pipeline` 或 `platform`。跨域工作流可另存相关域，但不得重复计算主归属。

## UI 生成 Prompt

```text
为 Asiral Helio 数据平台设计“自动化中心”桌面端界面。它是跨产品域基础底座，不是 Collect、Data Lake 或 ETL Pipeline 中的第四个业务产品。

保持现有紧凑、专业、深浅主题兼容的数据平台视觉。全局顶栏左侧保留当前产品域切换器；右侧在原“模板管理 + 任务调度”位置放置常驻“自动化中心”入口和图标式“组织与权限”入口。删除租户、团队切换器与 PRODUCTION 标签。

自动化中心包含模板库、工作流、编排调度、任务中心四个页签。右侧放置产品域筛选器：全部产品域、Collect、Data Lake、ETL Pipeline、Platform；筛选状态跨页签保持。列表对象显示产品域、对象类型、状态、进度和更新时间。

模板库统一目录和版本，但不强行统一采集 YAML、ETL 处理器等内部 Schema。编排调度管理触发规则、任务路径、启停和 Beat 重载。任务中心管理实际运行，并提供启动、暂停、继续、重启、取消和删除。

组织与权限是独立平台管理页面，包含租户、团队、用户、角色；不要放进系统设置或业务产品域。系统设置仅表达个人界面偏好，例如字体大小、颜色、主题、语言。

避免装饰性大卡片；使用紧凑表格、稳定的产品域颜色、清晰空状态和服务不可用反馈。所有可见按钮必须产生导航、表单、持久化操作或明确反馈。
```
