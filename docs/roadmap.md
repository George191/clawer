## 2. Phase 1: MVP（8 周）

### 2.1 目标

**让数据中台跑起来**：支持 4 种数据源接入，通过 DAG 调度编排完整 ETL 链路，提供数据 API 查询能力。

### 2.2 Sprint 分解

#### Sprint 1（第 1-2 周）：基础设施搭建

| 任务 | 负责人 | 估时 | 产出 | 依赖 |
|------|--------|------|------|------|
| 新增数据库 Schema 和表 (ADS, meta_*, quality_*) | 后端 | 1d | SQL 迁移脚本 | — |
| 适配器基类重构，支持新数据源类型 | 后端 | 2d | `app/adapters/base.py` 更新 | — |
| API 数据源适配器实现 | 后端 | 3d | `app/adapters/api_source.py` | 适配器基类 |
| 文件上传适配器 + API | 后端 | 2d | `app/adapters/file_upload.py` + 上传路由 | 适配器基类 |
| DB 同步适配器（PostgreSQL/MySQL） | 后端 | 3d | `app/adapters/db_sync.py` | 适配器基类 |
| 前端：数据源管理页面 | 前端 | 3d | `DataSources.vue` | API |
| 集成测试：4 种数据源接入 | 后端 | 2d | 测试报告 | 所有适配器 |

**Sprint 1 验收标准**：
- ✅ 能通过 Web 界面注册 API 数据源并定时拉取

- ✅ 爬虫采集正常运行（回归测试）
